SVM 背后的数学 · 第 1 篇

拉格朗日乘子：为什么只有支持向量算数

昨天说到 SVM 要在"所有点都在虚线外侧"的条件下让 ‖w‖ 最小。这类"带条件的最小化"就用拉格朗日乘子来解。这一页先用一个二维小问题把它讲清楚，再回到 SVM。每张图都可以拖动。

0先认识符号 ∇：梯度

下面会反复出现 ∇f，读作"f 的梯度"（∇ 这个符号叫 nabla）。它就是把 f 对每个变量的导数排成一个向量。

  1. 一个变量：导数就是斜率。f(x) = x²，导数 f′(x) = 2x。在 x = 1 处斜率是 2：x 往右挪一点点，f 大约增加它的 2 倍。
  2. 两个变量：偏导数。f(x, y) = x² + y² 有两个变量，斜率要分方向说。只动 x、把 y 当常数求导，得到 ∂f/∂x = 2x，叫对 x 的偏导数；只动 y，得到 ∂f/∂y = 2y。∂ 是偏导的符号，算法和普通求导一样，只是把其他变量当成常数。
  3. 把偏导数排成向量，就是梯度。
∇f = ∂f/∂x∂f/∂y = 2x2y
在哪个点∇f说明
(1, 1)22指向右上方，背离原点
(2, 0)40指向正右方；离原点更远，箭头更长
(0, 0)00碗底，往哪走都不会立刻变陡，梯度为零

梯度有两个几何含义，后面全靠它们：

  • 方向：指向 f 增长最快的方向。f = x² + y² 像一个碗，梯度永远指向背离原点、往碗壁上爬的方向。
  • 长度：f 在这一点、沿最陡方向的变化速率。离原点越远碗越陡，梯度越长。下面细说。

"长度 = 变化速率"分两种情况

梯度的长度告诉你：沿梯度方向走距离 d，f 大约增加 ‖∇f‖ × d。这个"大约"在两种函数上表现很不一样。两张图都从一个点出发、沿梯度方向走，右边的小图把实际增加量和按梯度长度预测的增加量画在一起。

情况一 · 线性函数 f = 3x + 4y，从原点出发，∇f = 34，长度 5

实际增加
按起点速率预测：5 × d

5 = ‖∇f‖ = √(3² + 4²)，即起点处的梯度长度。实际增加 = 终点的 3x + 4y 减去起点的 0。

差

线性函数像一个倾斜的平面，处处一样陡，所以等高线是等间距的平行直线，相邻两条相差 1，间距都是 1/5 = 0.2。不管走多远，实际增加都正好等于 5 × d，右边两条线完全重合。走 0.2 到达 f = 1 的等高线，走 1 到达 f = 5。

2.83 = ‖∇f(1, 1)‖ = √(2² + 2²)，即起点处的梯度长度。实际增加 = 终点的 x² + y² 减去起点的 2。

差

碗形函数越往外越陡，等高线圈一圈比一圈挤。把 d 拖到很小（比如 0.05），实际增加和预测几乎一样；走得越远，实际增加越超过预测，右边的曲线往上弯离了直线。这里的差正好是 d²：实际增加 = 2.83d + d²。

所以梯度的长度是 f 在这一点、沿最陡方向的变化速率，和车速是一个概念：仪表盘显示 60 km/h，是说按现在的速度开 1 小时会走 60 公里，但下一秒速度就可能变。线性函数速度恒定，预测永远准；弯曲函数只在很小的一步内准。

另外一个性质：梯度总是垂直于等高线。沿等高线走，f 不变；沿梯度走，f 涨得最快。这两个方向互相垂直。

1问题：带着条件找最小值

先看一个比 SVM 简单得多的问题：

最小化 f(x, y) = x² + y²　　条件：x + y = 2

f 就是点到原点距离的平方。没有条件时，最小值显然在原点。但条件要求点必须待在直线 x + y = 2 上，所以问题变成：直线上哪个点离原点最近？

图里的圆圈是 f 的等高线：同一个圆上的点 f 值相同，越往外 f 越大。紫色直线是约束。拖动滑块，让点沿着直线走，看 f 怎么变。

点的坐标
f = x² + y²
两个箭头的夹角

红箭头是 f 的梯度 ∇f，指向 f 涨得最快的方向。紫箭头是约束的梯度 ∇g，垂直于直线。

2关键观察：最优点处两个箭头平行

拖到 f 最小的地方（点 (1, 1)），会看到两件事同时发生：等高线圆刚好和直线相切，红箭头和紫箭头指向同一个方向。

为什么必须平行？如果红箭头 ∇f 不垂直于直线，它就有一部分沿着直线方向。那你沿直线往反方向走一点点，f 就会变小，说明这里还不是最小值。只有当 ∇f 完全垂直于直线、也就是和 ∇g 平行时，沿直线往哪边走 f 都不会再变小。

"平行"写成式子就是一个箭头是另一个的倍数：

∇f = λ · ∇g

这个倍数 λ（读作 lambda）就是拉格朗日乘子。它只是一个数，告诉你"在最优点，目标的梯度是约束梯度的几倍"。

3λ 的含义和不等式约束

λ 不只是个辅助数字，它有一个具体含义：约束收紧一点，最优值会变差多少。在图 1 的最优点 (1, 1)，∇f = 22 正好是 ∇g = 11 的 2 倍，所以 λ = 2。它的意思是：如果把条件从 x + y = 2 改成 x + y = 2.1，最小值大约增加 2 × 0.1 = 0.2。

SVM 的约束是不等式（"分数至少为 1"），所以再看 x + y ≥ c：点只要在直线上或直线右上方就行。这时会出现两种情况，拖动 c 看看：

规律只有一条，记住它就够了：

约束的状态最优点在哪λ
没碰到（原点本来就满足条件）在可行区域内部，约束可有可无= 0

两种情况合起来写成 λ · (x + y − c) = 0：要么 λ 是 0，要么点正好在边界上。这叫互补松弛，SVM 的支持向量就是从这句话里来的。

4回到 SVM

先回顾一下 SVM 要做什么（下面图 3 就是一个实例，可以对照着看）：

  1. 数据：每个 trial 是平面上的一个点，横坐标是 PO7 的电压，纵坐标是 PO8 的电压。每个点知道自己是脸 A 还是脸 B。
  2. 打分：给每个点算一个分数。写法和各符号见下面。
x = x₁x₂ = PO7 电压PO8 电压　　　w = w₁w₂ = PO7 的权重PO8 的权重
分数 = wTx + b = w₁x₁ + w₂x₂ + b

T 是转置：wT = (w₁　w₂) 是把竖着的 w 翻成一行。一行乘一列得到一个数，即 w₁x₁ + w₂x₂。

符号是什么图 3 里的值
x电压向量，一个 trial 的数据：x₁ 是它在 PO7 的电压，x₂ 是在 PO8 的电压。每个点有自己的 x。4 号点：−3.0−1.9 μV
w权重向量：w₁ 是 PO7 的权重，w₂ 是 PO8 的权重。所有点共用同一个 w，是 SVM 训练要找的。绝对值大，说明这个电极对分类影响大；正号表示这个电极电压越高，分数越偏向 B，负号则偏向 A。1.19−0.92
b偏置：一个常数，所有点共用，把分界线整体平移。也是训练要找的。0.84

代入 4 号点：

分数 = (1.19　−0.92) −3.0−1.9 + 0.84 = −3.58 + 1.74 + 0.84 ≈ −1.00

和图 3 表格里 4 号点的分数一致：正好是 −1，所以它贴在 A 侧的虚线上。权重的符号也和数据对得上：图 3 里 B 类的点 PO7 偏高、PO8 偏低，所以 w₁ 为正、w₂ 为负。

分数 = 0 的点连起来是分界线（实线），分数 = +1 和 −1 的点连起来是两条虚线。正分判成 B，负分判成 A。特征有 60 个时，w 和 x 就各有 60 行，wᵀx = w₁x₁ + w₂x₂ + … + w₆₀x₆₀，写法不变。

  1. 条件：每个点都必须在自己那一侧的虚线外面。每个数据点带一个条件，14 个点就是 14 个条件：
B 类的点：wTx + b ≥ +1　　　A 类的点：wTx + b ≤ −1
  1. 目标：在满足所有条件的前提下，让 margin 最宽。
margin = 2 / ‖w‖，　　‖w‖ = √(w₁² + w₂²)

‖w‖ 是 w 的长度，图 3 里 ‖w‖ = √(1.19² + 0.92²) ≈ 1.51。下面推导 margin 为什么是 2/‖w‖。

推导 · margin = 2 / ‖w‖

设定

  • 分界线（实线）：分数为 0 的点，即 wᵀx + b = 0
  • 虚线：分数为 1 的点，即 wᵀx + b = 1（另一条是 −1）
  • margin = 两条虚线之间的垂直距离 = 2 ×（虚线到实线的垂直距离）

所以只要算出虚线到实线的垂直距离 d。

第 1 步：垂直于分界线的方向

打分函数对 x₁ 求偏导得 w₁，对 x₂ 求偏导得 w₂，所以它的梯度就是 w。梯度垂直于等高线（第 0 节），分界线是"分数 = 0"的等高线，所以 w 垂直于分界线。把它缩成长度为 1 的方向向量：

u = w‖w‖

u 是"垂直于分界线、长度为 1"的方向。

第 2 步：从虚线上一点出发，沿 −u 走 d

取虚线上任意一点 x₀，它满足 wᵀx₀ + b = 1。沿 −u 方向（朝分界线）走距离 d，到达

x₀ − d·u

第 3 步：算新点的分数

wT(x₀ − d·u) + b = (wTx₀ + b)= 1，因为 x₀ 在虚线上 − d · wTw‖w‖

而 wᵀw = w₁² + w₂² = ‖w‖²，所以

新点的分数 = 1 − d · ‖w‖²‖w‖ = 1 − d‖w‖

意思是：分数从 1 开始，每走 1 单位就减少 ‖w‖。

第 4 步：要求到达分界线

我们想知道走多远才到分界线。分界线就是分数等于 0 的地方，所以把第 3 步算出的"新点的分数"令为 0。下面用图 3 的真实结果（‖w‖ ≈ 1.51）走一遍：从 13 号点（它正好在 +1 那条虚线上）出发，沿 −u 朝分界线走。拖动 d，看分数怎么降到 0。

两行分数始终相等：一个是把新点的坐标真的代入 wᵀx + b 算出来的，一个是第 3 步的公式。分数每走 1 单位减少 1.51，所以右边是一条斜率为 −1.51 的直线，它穿过 0 的地方就是 d = 0.66。继续走到 d = 1.33，分数变成 −1，到了另一条虚线，这整段就是 margin。

令分数 = 0，解关于 d 的一元一次方程：

1 − d‖w‖ = 0　⇒　1 = d‖w‖　⇒　d = 1‖w‖

代入数字：d = 1/1.51 ≈ 0.66，和表里分数变成 0 的位置一致。两边各一条虚线，所以

margin = 2d = 2‖w‖

‖w‖ 越小，margin 越宽，所以目标是：

在上面 14 个条件下，找使 ‖w‖ 最小的 w 和 b

所以 SVM 和前面的小问题是同一种事：带着不等式条件找最小值。区别只是条件从 1 个变成了"每个数据点 1 个"。一一对上：

小问题SVM
要最小化的东西：点到原点的距离要最小化的东西：w 的长度（等于让 margin 最宽）
1 个条件：点要在紫色直线的右上方14 个条件：每个数据点都要在虚线外面
1 个拉格朗日乘子 λ14 个乘子，每个点一个。SVM 里习惯叫它 α（alpha）
条件没碰到 → λ = 0这个点离分界线很远，没贴到虚线 → 它的 α = 0，对结果毫无影响
条件顶住了 → λ > 0这个点正好贴在虚线上（分数正好是 +1 或 −1）→ 它的 α > 0，这就是支持向量

为什么 w 由支持向量拼出来

训练 SVM 时，14 个点的坐标都是已知的数据，要找的是 w₁、w₂、b。所以这里换一个视角：w₁、w₂、b 是变量，点的坐标是常数。第 i 个点的坐标记作 xᵢ = xᵢ₁xᵢ₂（xᵢ₁ 是它在 PO7 的电压，xᵢ₂ 是在 PO8 的电压），它的拉格朗日乘子记作 αᵢ。

等价目标函数。目标是让 ‖w‖ = √(w₁² + w₂²) 最小，但根号不好求导。长度不会是负数，让 ‖w‖ 最小和让 ‖w‖² 最小找到的是同一个 w，所以改为最小化

F = ½‖w‖² = ½(w₁² + w₂²)

这里把 F 叫做等价目标函数：它和"让 margin 最宽"结果完全一样，只是更好求导。前面的 ½ 是为了求导时把 2 消掉。它和第 1 节的 x² + y² 是同一个形状：把每组权重 (w₁, w₂) 看成"权重平面"上的一个点，F 就是它到原点距离平方的一半。所以 SVM 问的是：在 14 个条件都满足的前提下，找离原点最近的 w。

要用的是第 2 节的"梯度平行"。先写出三类函数，都对 w₁、w₂ 求偏导，竖着排起来就是关于 w 的梯度：

函数写出来关于 w 的梯度例子
等价目标函数F = ½(w₁² + w₂²)w₁w₂ = w和第 0 节的 x² + y² 一样，只是变量换成了 w₁、w₂
B 类点 i 的条件
要求 Gᵢ ≥ 1		Gᵢ = xᵢ₁w₁ + xᵢ₂w₂ + bxᵢ₁xᵢ₂ = xᵢ13 号点：G = −2.4w₁ − 3.3w₂ + b，梯度 −2.4−3.3
A 类点 i 的条件
分数 ≤ −1，两边乘 −1 改写成 Gᵢ ≥ 1		Gᵢ = −(xᵢ₁w₁ + xᵢ₂w₂ + b)−xᵢ₁−xᵢ₂ = −xᵢ4 号点：G = 3.0w₁ + 1.9w₂ − b，梯度 3.01.9

目标 F 是什么：让 margin = 2/‖w‖ 最宽，就是让 ‖w‖ = √(w₁² + w₂²) 最小。根号不好求导，而最小化 ‖w‖ 和最小化 ‖w‖² 得到的是同一个 w，所以改用平方；前面的 ½ 只是为了求导时消掉 2。它和第 1 节的 x² + y² 是同一个形状：在 (w₁, w₂) 平面上，F 是到原点距离平方的一半。所以 SVM 就是在满足 14 个条件的前提下，找离原点最近的 w。

在分数 xᵢ₁w₁ + xᵢ₂w₂ + b 里，点的坐标是 w₁、w₂ 的系数，所以对 w 求偏导留下来的就是坐标。A 类多一个负号，是因为把"≤ −1"翻成了"≥ 1"。

第 2 节只有一个条件，最优点满足 ∇f = λ∇g。有多个条件时，变成目标的梯度 = 各个条件的梯度乘上各自的乘子，再加起来：

∇F = Σi αi ∇Gi

直观理解：最优点同时顶着好几条边界，目标的梯度必须能由这些边界的方向组合出来；否则还能贴着边界往某个方向挪一点，让目标继续变小。把表里的三个梯度代进去：

w = ΣB 类 αi xi − ΣA 类 αi xi

再用第 3 节的结论：没顶住虚线的点 αᵢ = 0，它那一项是零向量，加了等于没加。真正留下来的只有支持向量，这就是"分界线只由支持向量决定"的数学含义。

顺带对 b 求偏导。目标 F 里没有 b，所以对 b 的偏导是 0；B 类的 Gᵢ 对 b 的偏导是 +1，A 类是 −1。按同样的"梯度平行"：

0 = ΣB 类 αi − ΣA 类 αi

也就是 A 类的 α 加起来等于 B 类的 α 加起来。图 3 里：0.618 + 0.514 = 1.132，正好等于 13 号点的 α。第 5 节说 SMO 每次必须同时调两个 α，就是因为这个条件。

顺便回答一个前面埋下的问题：为什么 w 垂直于分界线？把打分规则对 PO7 求偏导，得到的就是 PO7 的权重；对 PO8 求偏导，得到 PO8 的权重。所以打分规则的梯度就是 w 本身。分界线是"分数 = 0"的等高线，而梯度总是垂直于等高线（第 0 节），所以 w 垂直于分界线。打分规则又是线性的（第 0 节的情况一），所以沿 w 方向走，分数的增长速率恒定为 w 的长度。

5剩下的一步：对偶问题和 SMO

既然 w 可以用 α 拼出来，那就不用直接去找 w 了，改成去找那 14 个 α。换成"找 α"之后的问题叫对偶问题，它和原问题答案完全一样，只是换了一组未知数。昨天说的 SMO 算法解的就是这个问题。

对偶问题里有一个条件：A 类所有点的 α 加起来，必须等于 B 类所有点的 α 加起来。图 3 里可以验证：A 类是 0.618 + 0.514 = 1.132，B 类是 1.132，正好相等。如果只改一个 α，两边就不相等了，所以 SMO 每次至少要同时调两个 α，一个变了另一个跟着补上。这就是它"每次挑两个"的原因。

软间隔版本（有参数 C 的那种）只多了一个条件：每个 α 都不能超过 C。也就是每个点的影响力有上限，越界的点不能无限拉扯分界线。

✓一句话串起来

拉格朗日乘子是"带条件求最小值"的方法：最优点处，目标的梯度和约束的梯度平行，倍数就是乘子。不等式约束里，没顶住边界的约束乘子为 0。SVM 给每个数据点一个约束，顶住虚线的点乘子大于 0，它们就是支持向量，分界线只由它们决定。
